Логика игры: Шаг 3 - Движение

Самая важная часть — функция move_snake(). Она вычисляет новую позицию головы при каждом шаге.

  • Если голова выходит за границы экрана или врезается в собственное тело — игра заканчивается.
  • Если голова совпадает с позицией еды, счет увеличивается, а хвост не обрезается (змейка растет).
func move_snake():
    direction = next_direction
    var head = snake[0]
    var new_head = head + direction
    
    # Проверка столкновения со стенами
    if new_head.x < 0 or new_head.x >= GRID_WIDTH or new_head.y < 0 or new_head.y >= GRID_HEIGHT:
        game_over()
        return
    
    # Проверка столкновения с хвостом
    for i in range(1, snake.size()):
        if snake[i] == new_head:
            game_over()
            return
    
    snake.push_front(new_head)
    
    # Поедание еды
    if new_head == food_position:
        score += 1
        spawn_food()
    else:
        snake.pop_back() # Удаляем хвост, если еда не съедена
