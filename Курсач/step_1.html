Логика игры: Шаг 1 - Переменные

Теперь, когда наша сцена и интерфейс настроены, пришло время вдохнуть в игру жизнь. Мы напишем скрипт, который будет управлять движением змейки, обработкой столкновений, поеданием еды и отрисовкой графики.

Выберите корневой узел Main, нажмите кнопку "Прикрепить скрипт" и назовите его main.gd.

Наша игра работает на невидимой сетке. Начнем с объявления констант для размеров этой сетки, а также создадим переменные для хранения состояния игры, направления движения и самой змейки.

extends Node2D

const GRID_SIZE = 20
const GRID_WIDTH = 30
const GRID_HEIGHT = 20

enum GameState { START, PLAYING, PAUSED, GAME_OVER }

var snake: Array[Vector2i] = []
var direction: Vector2i = Vector2i.RIGHT
var next_direction: Vector2i = Vector2i.RIGHT
var food_position: Vector2i
var score: int = 0
var state: GameState = GameState.START
Примечание
Мы используем типизированный массив Array[Vector2i] для хранения координат каждого сегмента тела змейки. Голова змейки всегда находится под индексом 0.
