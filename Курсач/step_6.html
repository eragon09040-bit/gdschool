Логика игры: Шаг 6 - Сохранение рекордов

Чтобы игра ощущалась полноценной, научим её запоминать лучший результат (High Score).

Для сохранения рекорда мы используем встроенный класс FileAccess, который записывает данные в специальную пользовательскую папку user://. Это гарантирует, что рекорд сохранится на жестком диске даже после полного закрытия игры.

func load_high_score():
    var file = FileAccess.open("user://highscore.dat", FileAccess.READ)
    if file:
        high_score = file.get_32()
        file.close()

func save_high_score():
    var file = FileAccess.open("user://highscore.dat", FileAccess.WRITE)
    if file:
        file.store_32(high_score)
        file.close()
Примечание
Функция load_high_score() вызывается один раз при старте игры в _ready(), а save_high_score() вызывается каждый раз, когда текущий счет (score) превышает рекорд.
