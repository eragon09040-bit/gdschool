Логика игры: Шаг 4 - Отрисовка

Вместо использования множества отдельных узлов (спрайтов) для каждого кусочка змейки, мы рисуем игру программно с помощью функции _draw(). Это очень эффективный способ для простых 2D-игр. Мы задаем цвета в стиле темы Godot Engine.

func _draw():
    var bg_color = Color("#202531")
    var head_color = Color("#478cbf")
    var food_color = Color("#fc7f7f")
    
    # Отрисовка фона
    draw_rect(Rect2(0, 0, GRID_WIDTH * GRID_SIZE, GRID_HEIGHT * GRID_SIZE), bg_color)
        
    # Отрисовка змейки
    for i in range(snake.size()):
        var segment = snake[i]
        var is_head = (i == 0)
        var rect = Rect2(segment.x * GRID_SIZE + 1, segment.y * GRID_SIZE + 1, GRID_SIZE - 2, GRID_SIZE - 2)
        
        if is_head:
            draw_rect(rect, head_color)
        else:
            draw_rect(rect, Color("#407ea9"))
            
    # Отрисовка еды
    var food_center = Vector2(food_position.x * GRID_SIZE + GRID_SIZE / 2, food_position.y * GRID_SIZE + GRID_SIZE / 2)
    draw_circle(food_center, GRID_SIZE / 2 - 3, food_color)
Важно
Функция _draw() вызывается движком только один раз. Чтобы заставить Godot перерисовывать кадр при каждом шаге змейки, мы вызываем метод queue_redraw() в нашем игровом цикле _process(delta).
